Technology Architecture & Implementation Stack

Photogrammetric Computer Vision & Cadastral GIS Vectorization Framework

Tier 1: Presentation & Vector GIS
HTML + CSS + JavaScript Canvas GIS
HTML5 Canvas Vanilla JS ES6+ CSS3 Glassmorphism SVG Vector Renderer
High-performance interactive web mapping client featuring sub-pixel canvas vector rendering, split-curtain comparison sliders, multi-layer GIS visibility toggles, interactive geodesic distance/area calculators, and instantaneous GeoJSON/CSV serializations.
Tier 2: Backend Orchestrator
Python 3.11 + Flask / FastAPI
Flask RESTful API Celery Workers Async I/O OGC WMS / WFS
Handles aerial orthomosaic file uploads, sensor EXIF photogrammetry decoding, tile-pyramid partitioning, asynchronous batch GPU dispatching, and REST endpoints for GIS vector querying and cadastral certificate generation.
Tier 3: Computer Vision Preprocessing
OpenCV + GDAL / Rasterio
OpenCV 4.9 CLAHE Contrast GDAL Warp GeoTIFF Tiling
Performs radiometric normalization, contrast-limited adaptive histogram equalization (CLAHE), orthorectification correction, spatial resolution downsampling to standard GSD grids, and seamless sliding-window tile generation for neural inference.
Tier 4: Deep Learning Segmentation
YOLOv8-Seg + SAM + DeepLabV3+
YOLOv8-Seg Segment Anything (SAM) DeepLabV3+ TensorRT FP16
Multi-task deep convolutional neural networks extracting building rooftop masks, road corridor centerlines, boundary walls, and fence lines. Incorporates promptable Segment Anything Model (SAM) for zero-shot boundary delineation.
Tier 5: Geospatial Topology Engine
GeoPandas + Shapely + PyProj + Folium
GeoPandas Shapely Polygon Ops Douglas-Peucker Folium / Leaflet
Converts raw raster probability masks into topologically sound planar polygon graphs. Applies Douglas-Peucker simplification, eliminates slivers, ensures zero overlapping polygons, projects coordinates to EPSG:32643 UTM grids, and encodes official GeoJSON FeatureCollections.
